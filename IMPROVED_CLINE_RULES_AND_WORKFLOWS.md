```

```

3. VERIFY: Check existing configs for similar purpose
4. APPLY: Use exact patterns from working configs
5. TEST: Verify with existing test infrastructure
6. DOCUMENT: Update memory bank with changes
```

### **Workflow 2: Bug Fixes**
```
1. IDENTIFY: Analyze issue with existing files
2. LOCATE: Find root cause in specific files
3. FIX: Apply minimal necessary changes
4. VERIFY: Test with existing test suites
5. CONFIRM: Ensure main executables still work
6. SUMMARIZE: Provide clear completion message
```

### **Workflow 3: Feature Enhancements**
```
1. ASSESS: Check if feature already exists

### **Workflow 4: File Management**
